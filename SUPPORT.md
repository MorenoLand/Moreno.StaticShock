## Ask a question

Open a GitHub issue. Include:

- what you are trying to do, with the target named only if you own it
- the exact command and the full error
- the output of `python static_shock.py doctor`
- the commit hash (`git rev-parse HEAD`)
- OS, Python version, and `i686-w64-mingw32-gcc --version`
- a minimal reproduction, if one exists

Do not attach the original executable, game assets, keys or proprietary code. A hash and a short
synthetic sample are enough.

## Report a bug

Use the bug report form. A good report has the expected result, the actual result and the first
incorrect value you observed, not only the final crash.

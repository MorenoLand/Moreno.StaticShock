# Code of conduct

Short version: be a decent person. This is a technical project, not a place to fight.

## Expected

- Treat people with respect, including when you disagree.
- Critique code, evidence and decisions, not people.
- Assume good faith; ask before escalating.
- Keep discussion on the project and on software people legally own.
- Help newcomers find the docs and the evidence rules.

## Not acceptable

- Harassment, threats, slurs, sexual attention or personal attacks.
- Publishing someone's private information.
- Piracy, requests for pirated software, or instructions to bypass licence checks.
- Deliberately fake evidence, fabricated test results or misleading claims of correctness.
- Spam, drive-by self-promotion or unrelated political campaigning.

## Scope

This applies to issues, pull requests, discussions, commit messages and any project space.

## Enforcement

The maintainer may edit or remove content, close threads, or block accounts. Enforcement is
proportional: a correction for a first mistake, stronger action for repeated or serious behaviour.

Report a problem to the maintainer through GitHub. Reports are handled privately. Do not open a
public issue about a conduct report.

## Attribution

This is an original, shortened code of conduct. It is not a legal document; it is the standard
this project expects.
